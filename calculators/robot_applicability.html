Robot Applicability Scorer

Pre-loaded with customer data — scores each SKU category for Origin (P2G) and Array + NeuraGrasp (R2G) fit

What this calculator does: Evaluates each product category and SKU characteristic against the operating profile of each Locus robot. Origin is a P2G (picker-to-goods) cobot that escorts human pickers and carries totes — it excels where human travel is the bottleneck and picks are batch-clusterable. Array + NeuraGrasp is an R2G (robot-to-goods) autonomous system — it excels with uniform, robotically-graspable items on extended operating schedules.

Key output: H&B routes to Array (72% of pick volume, uniform items, NeuraGrasp-suitable). Apparel routes to Origin + human collaboration (non-uniform items, variable folding/handling). This is the category-level routing decision that drives the two-phase deployment plan.
